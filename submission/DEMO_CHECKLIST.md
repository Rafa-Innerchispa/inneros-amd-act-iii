# Demo Checklist

## Required assets
- [ ] Public GitHub repository
- [ ] Cover image
- [ ] Demo URL
- [ ] Application/platform URL
- [ ] Video presentation
- [ ] Slide deck
- [ ] Final project description

## Judge flow
1. Show the task graph.
2. Trigger a multi-step workload.
3. Show local-first routing to AMD local compute.
4. Trigger a workload that requires elastic/cloud capacity.
5. Show routing reason codes and target hardware/model identity.
6. Show latency/throughput metrics.
7. Open the execution evidence bundle.
8. Verify the SHA-256 manifest.
9. Replay the historical run without live refresh.
10. Show Human Time Returned / business KPI.

## Evidence gate
- [ ] Every benchmark has raw machine-readable output.
- [ ] Every claimed AMD target has recorded hardware/runtime identity.
- [ ] Experimental R9700/HyperLoom claims are clearly labeled.
- [ ] Pre-hackathon work and ACT III-period work are separated.
- [ ] No estimated KPI is presented as measured.

## Fallback demo
Prepare a fully recorded evidence bundle and offline replay path in case internet or cloud access fails during judging.
